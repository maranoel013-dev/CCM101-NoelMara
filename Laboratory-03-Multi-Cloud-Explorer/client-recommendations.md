# Client Recommendations

## Client A – Startup Company
**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** AWS is a good choice for a startup because the company has a limited budget but may grow quickly. AWS uses a pay-as-you-go system, so the company only pays for what it uses and does not need to spend a lot of money at the beginning. AWS also has many different services, so the company can easily add more tools as it grows. Its resources can also be increased quickly when more users start using the app.

**Services:**
1. Amazon EC2 – Used to host the servers for the mobile app.
2. Amazon S3 – Used to store app files, pictures, videos, and backups.
3. Amazon RDS – Used to manage the app's database without needing a full-time database administrator.

---

## Client B – University
**Recommended Platform:** Microsoft Azure

**Explanation:** Azure is a good choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with these Microsoft products, making it easier for the university to move its systems to the cloud. The university can also move its systems little by little instead of changing everything at once. Azure allows the university to keep some systems on campus while using cloud services for others.

**Services:**
1. Microsoft Entra ID – Connects the university's existing Active Directory to the cloud.
2. Azure Virtual Machines – Used to run servers that are currently on campus.
3. Azure Virtual Network – Creates a secure connection between the university's campus systems and Azure.

---

## Client C – AI Research Company
**Recommended Platform:** Google Cloud Platform (GCP)

**Explanation:** GCP is a good choice because the company focuses on AI and machine learning. Google Cloud provides powerful tools for creating, training, and running AI models. It also provides strong computing power for handling large amounts of data. This makes GCP suitable for AI research that needs a lot of processing power.

**Services:**
1. Vertex AI – Used to build, train, and run machine learning models.
2. Compute Engine – Provides powerful computers for AI and research work.
3. BigQuery – Used to quickly analyze large amounts of research data.

---

## Client D – Global E-Commerce Company
**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** AWS is a good choice because this company serves customers around the world and needs its website to stay online even when many people are shopping at the same time. AWS can automatically increase resources when traffic becomes high, such as during holiday sales. Its large global network also helps websites and applications stay fast and reliable for customers in different countries.

**Services:**
1. Amazon EC2 – Runs the website servers and can automatically add more servers when traffic increases.
2. Amazon S3 – Stores product pictures, files, and other website content.
3. Amazon RDS – Provides a managed and reliable database for storing customer and store information.

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|----------------------|----------------------|----------------|
| Startup Company | AWS | Pay-as-you-go pricing and easy scalability suit limited budgets and fast growth |
| Enterprise Organization | AWS | Widest range of services supports complex, large-scale operations |
| Microsoft Environment | Azure | Native integration with Windows Server, Active Directory, and Microsoft 365 |
| AI / Machine Learning | GCP | Strong AI/ML tools like Vertex AI and TensorFlow, built by the creator of Kubernetes |
| Kubernetes Deployment | GCP | Google created Kubernetes and offers the most optimized environment for it |
| Global Web Application | AWS | Extensive global infrastructure ensures high availability and fast performance worldwide |
