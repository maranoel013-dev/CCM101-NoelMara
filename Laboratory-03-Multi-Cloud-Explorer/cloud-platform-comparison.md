## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the broadest range of services among the three, since it was the first major cloud provider and has had the most time to build out its ecosystem. It provides hundreds of services covering compute, storage, databases, AI, and more, making it a common default choice for companies needing flexibility.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure best integrates with Microsoft technologies, since it works natively with Windows Server, Active Directory, and Microsoft 365. This makes it the easiest choice for organizations that already rely on Microsoft's software ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform is strongest in AI and Kubernetes, largely because Google created Kubernetes and has deep expertise in machine learning through tools like TensorFlow and Vertex AI. Its infrastructure also powers Google's own AI-driven products like Search.

### 4. Which cloud platform would you personally choose and why?
If I had to pick one, I'd go with Google Cloud Platform. My main interest is in AI, and GCP just has the best tools for that like Vertex AI for building machine learning models and ready-made APIs for things like speech recognition and natural language understanding. Since Google also created Kubernetes, GCP makes it easier to manage all the different parts an AI system needs, like understanding requests, processing language, and remembering past interactions. That combination makes it the most practical choice if I were building something like an AI assistant.
