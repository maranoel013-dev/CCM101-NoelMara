# Reflection

Out of the three cloud platforms, Google Cloud Platform impressed me the most because of its strength in Artificial Intelligence. I'm currently working on building an AI agent that can open tabs, launch software, and open folders, along with a simple AI assistant that can answer questions. Learning that GCP has tools like Vertex AI, and was built by the creators of Kubernetes, made me more interested in exploring it further, even though I'm still not fully confident using it yet.

While researching all three platforms, I noticed they are mostly similar in the basics — each offers a compute service, storage service, and identity management service, just under different names (like EC2 vs. Azure VMs vs. Compute Engine). The core building blocks of cloud computing are the same; what differs is branding, pricing, and which areas each provider specializes in.

This lab also showed me how business requirements affect platform choice. A startup with a limited budget benefits from AWS's pay-as-you-go pricing, a university already using Microsoft tools fits Azure due to its Active Directory integration, and an AI research company suits GCP because of its machine learning tools. There's no single "best" provider only the one that matches what a business already has and needs.

Acting as a Cloud Solutions Consultant taught me to think about a client's situation instead of just picking the most popular platform. AWS works well for flexible, pay-as-you-go needs, Azure fits Microsoft-based companies, and GCP stands out for AI work.

Finally, my GitHub portfolio improved a lot. Before, my README was mostly blank, but now my repository has multiple organized folders and files. I also learned Markdown formatting, and how to create, edit, and commit changes on GitHub.
